# FAQ 知识卡目录

- 每个 `route: faq` 意图对应一张卡，文件名与注册表 `knowledge` 字段一致。
- **知识卡格式规范**（判分器按信息点对齐，必须遵守）：
  1. 只放"事实型"内容：一个事实 = 一个信息点，编号 `[I1] [I2] ...`；

  3. 一卡 ≤300 token，超了就拆意图。
